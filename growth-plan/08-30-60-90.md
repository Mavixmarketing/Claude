# 08 — The 30/60/90 Day Plan

Targets: **Day 30 → $3,500/mo. Day 60 → $6,500/mo. Day 90 → $10,000/mo recurring** (plus project cash on top).

Every day below has a deliverable. If a day slips, don't skip it — push everything back one day. The order matters more than the dates.

---

## WEEK 1 — Foundation (no spending)

**Goal: prices raised, niche chosen, script rehearsed, reactivation sent.**

### Day 1 (Monday) — Decisions
- [ ] Read [`01-diagnosis.md`](01-diagnosis.md) and [`02-money-math.md`](02-money-math.md) fully
- [ ] **Pick your niche.** One industry. Write it down. Don't reopen the decision
- [ ] **Set new prices.** SEO $1,200 / $2,500. Ads $1,000. Websites $2,500+. Growth package $3,000
- [ ] Build List A (past clients), List B (dead leads), List C (current clients)
- [ ] Set up the pipeline spreadsheet

### Day 2 — Reactivation
- [ ] Send the win-back email to **every** past client, individually, from your real inbox
- [ ] Send the dead-lead email to every prospect who ever replied or got a quote
- [ ] **Call** your current clients — "how is this honestly going, what would make it better?"
- [ ] Build the reply-alert automation (30 min)

### Day 3 — Deliverability audit
- [ ] Run the full checklist in [`04-channels.md`](04-channels.md#the-deliverability-audit-do-this-before-sending-anything) on all 15 mailboxes
- [ ] Fix DMARC → `p=quarantine` minimum. **`p=none` is not enough in 2026**
- [ ] Add one-click List-Unsubscribe headers
- [ ] Seed-test inbox placement. If under 80%, fix before sending anything
- [ ] Confirm sending domains are variants — **never `mavixmarketing.com`**

### Day 4 — Sales prep
- [ ] Read [`05-sales-playbook.md`](05-sales-playbook.md)
- [ ] Memorise the 13 discovery questions
- [ ] Say the Frame out loud 10x. Say "$2,500 a month" out loud 20x
- [ ] Record a mock call. Watch it. Do it again
- [ ] Set up Cal.com, put the link everywhere

### Day 5 — White-label + partners
- [ ] Build a list of 30 small web design / branding agencies in your niche
- [ ] Send **20 white-label pitches** by hand
- [ ] Send 10 partner-referral pitches to freelance designers/devs
- [ ] Update LinkedIn profile to say the niche explicitly

### Day 6–7 — Cold email build
- [ ] Buy 4 sending domains (~$48/yr) if you need more than what you have
- [ ] Set up Tier 1 stack (~$115/mo) — see [`03-budget-tiers.md`](03-budget-tiers.md#tier-1--120month-lowest-paid-tier)
- [ ] Build first list: **500 prospects in your niche only**
- [ ] Verify every email
- [ ] Write the 4-email sequence
- [ ] Fix the LinkedIn sequence (no-pitch connect → post-accept DM)
- [ ] Start Upwork: bid 10 small fixed-scope jobs ($100–500) to farm reviews

**Week 1 target: 1–2 clients from reactivation. $1,500–3,000/mo.**

## WEEK 2 — Volume on

- [ ] Cold email live: **150/day**, scaling to 300/day by end of week
- [ ] LinkedIn: 20 profile views + 15 connections/day on the new sequence
- [ ] Upwork: 10 targeted proposals (verified-payment clients, posted <6h, <15 proposals)
- [ ] Follow up on every white-label pitch — **twice**
- [ ] Reply to every positive reply **by hand within 5 minutes**
- [ ] Send free audit videos to everyone who says yes — and to the good-fit ones who don't reply
- [ ] Weekly Loom to every current client. Start the habit now
- [ ] Take every sales call using the script. Notes after each on what went wrong

**Week 2 target: 5–10 conversations, 3–5 meetings booked.**

## WEEK 3 — Close

- [ ] Cold email: **300/day** sustained
- [ ] Run 5+ sales calls. Script open on second screen
- [ ] Same-day recap email after every call
- [ ] Work the follow-up sequence on every non-closer
- [ ] Deliver the Upwork small jobs brilliantly → collect reviews
- [ ] Follow up white-label pitches a third time. Book at least one call
- [ ] Send proposals via the proposal generator — **always with a booked review call**

**Week 3 target: 2–3 closes.**

## WEEK 4 — Consolidate

- [ ] Onboard new clients properly — Day 0 checklist, kickoff call, week-1 quick win
- [ ] Give existing clients 60-day price increase notice
- [ ] Review the numbers: emails sent, reply rate, meetings, close rate. **Find the weakest number and fix only that one**
- [ ] Finish the Google Maps pipeline (with verification + dedup + suppression)
- [ ] Ask every client and every past client for one specific referral

**DAY 30 TARGET: $3,500/mo recurring + project cash.**

Realistic composition: 2 win-backs ($1,800) + 1 new retainer ($1,500) + existing ($1,000) − any churn. Plus 1 website ($2,500 cash).

## The weekly scorecard

Track these seven numbers every Friday. Nothing else. If a number is bad, that's the only thing you work on the following week.

| Metric | Week 1 | Wk 2 | Wk 3 | Wk 4 | Target |
|---|---|---|---|---|---|
| Emails sent | | | | | 1,500–2,000/wk |
| Reply rate | | | | | **>3.5%** |
| Positive replies | | | | | 10+/wk |
| Meetings booked | | | | | 4–6/wk |
| Meetings held | | | | | 80% of booked |
| Closes | | | | | 1–2/wk |
| **MRR** | | | | | ↑ every week |

**How to read it:**

| Symptom | Real problem | Go to |
|---|---|---|
| Reply rate under 2% | Deliverability or list quality — not your copy | [`04-channels.md`](04-channels.md#the-deliverability-audit-do-this-before-sending-anything) |
| Replies but no meetings | Your reply handling / the offer | [`04-channels.md`](04-channels.md#handling-replies--do-not-automate-this) |
| Meetings but no closes | Sales process | [`05-sales-playbook.md`](05-sales-playbook.md) |
| Closes but flat MRR | **Churn — the real problem** | [`06-onboarding-retention.md`](06-onboarding-retention.md) |
| Everything low | Volume too low — send more | [`04-channels.md`](04-channels.md#volume-targets) |

## Rules for the next 90 days

1. **Sales before building.** 25 hrs/week selling, 5 hrs max building. Non-negotiable.
2. **Never discount. Reduce scope instead.**
3. **Reply to positive replies within 5 minutes, by hand.**
4. **Weekly Loom to every client. Never skip.**
5. **Follow up 7 times minimum.** 80% of deals close after touch 5.
6. **One niche.** No exceptions for 90 days, however tempting the off-niche lead.
7. **Every call ends with a date on the calendar.**
8. **Track the seven numbers every Friday.**

## If you only do five things

Realistically you won't do all of this. So if you do five things, do these:

1. **Raise your prices today.** Free, instant, 2–4x effect on everything downstream.
2. **Email every past client and dead lead this week.** Free. Fastest money available to you.
3. **Learn the sales script and rehearse it out loud.** Free. Doubles your close rate.
4. **Send 300 emails a day instead of 40.** ~$115/mo. Ends the volume problem permanently.
5. **Send 20 white-label pitches to other agencies.** Free. One partner is $2,000–4,000/mo from a single sale.

Those five cost about $115 and could realistically take you from $1,000 to $5,000+ inside 45 days.

The automations can wait. They'll still be there when you've got clients to run them for.
